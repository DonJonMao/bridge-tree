## 服务器操作

在仓库根目录更新代码，并将本机生成的 `repaired_chain_inputs_20260917.tgz` 放到服务器用户主目录。回归包包含原始实验输入，只在受控机器间传送，不提交 Git。

```bash
git pull --ff-only
tar -xzf ~/repaired_chain_inputs_20260917.tgz
bash scripts/run_repaired_chain.sh start
```

看状态、看实时日志、停止分别执行：

```bash
bash scripts/run_repaired_chain.sh status
bash scripts/run_repaired_chain.sh log
bash scripts/run_repaired_chain.sh stop
```

同一后台入口运行中再次 start 会报告现有进程，不启动第二份。停止之后再次 start 会开始另一轮新的验收与实验，不续接旧实验。

本机不能连通服务器模型接口，所以本地测试通过和输入重建完成不能写成“真实回归已通过”或“全量已启动”。服务器实际验收结果以 `acceptance.json` 为准。
