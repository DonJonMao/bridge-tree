## 早期试验的问题与修复起点（v3 / v4）

1. **导航停留在同一栏目。** 早期 v3 记录中，第一题 joint 访问 12 页，主要围绕 Grants 及获奖年份，23 次模型调用后仍没有目标事实。零格式修复说明当时的失败已经不是 JSON 问题。

3. **空阅读与 unknown 指令冲突。** 公共提示曾要求范围不适用时返回 unknown/irrelevant，Web 协议要求没有适用新证据时返回空结果。错误 unknown 会形成来源义务和失败草稿，挤占后续预算。v3 时 Web 侧已精确协调这三处提示；该轮 joint 的 14 个阅读批次全部合法空读、零修复，但导航仍失败。

5. **环境会干扰判断。** v3 第二题两组都因 tokenizer 连接失败提前终止。早期试验另有模型 HTTP 重试实际消耗预算。这些与算法错误分别记录，不当作正确结果或算法改善。

## v4 提出的两个算法环节

- **探索复盘：** 若同一事实与权限状态下，连续多个不同页面的实际阅读窗口都为空，在原本就要支付的导航调用中，对照当前路线与尚未访问的首页入口。保留现有备选、所有链接和停止规则，不自动选 URL，不把空窗口当整条分支无答案。
- **实体与关系核对：** 从当前请求已经可见的原文中，按文档前置最早可见片段，与请求范围并列。要求跨实体、跨事件的身份桥接有原文依据；程序不自动判同一实体、不新增事实或证据权限。
